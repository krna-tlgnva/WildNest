# WildNest

A modern Flutter e-commerce application inspired by the Wildberries shopping experience.  
The project demonstrates advanced navigation architecture using `go_router` with clean UI structure, responsive routing, and interactive shopping functionality.

## ✨ Features

- Web-friendly navigation using `go_router`
- Home screen with product catalog
- Product details page
- Shopping cart system
- Favorite product toggle
- Add-to-cart interactions
- Mock product data integration
- Custom unknown route error screen
- Responsive and scalable Flutter architecture

## 🛠️ Tech Stack

- Flutter
- Dart
- go_router
- Material Design

## 📱 Screens

- Home Screen
- Product Details Screen
- Cart Screen
- Error / Unknown Route Screen

## 🚀 Navigation Architecture

The application uses `go_router` for declarative routing and clean URL management.

Example routes:
/product/:id
/cart
